# Schema

描述性字段约定，供人类与 Agent 对照。不是强制 JSON Schema 校验器。

| 文件 | 对应路径 |
|------|----------|
| `book.schema.yaml` | `00_meta/book.yaml` |
| `character.schema.yaml` | `02_canon/characters/<slug>.yaml` |
| `lore.schema.yaml` | 地点 / 势力 / 物品 / 规则 / 词条 |
| `continuity.schema.yaml` | `03_continuity/*` |
| `volume.schema.yaml` | `05_manuscript/**/volume.yaml` |
